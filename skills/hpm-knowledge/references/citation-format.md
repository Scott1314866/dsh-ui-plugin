# Citations

Web: `[Article title — applicable SDK/chip if known](original_url)` beside the claim. A fetched date is not the article's publication or modification date.

SDK: title, actual SDK version, relative file and true line range; include commit/dirty state if returned. The UI can open local files through Harness; do not invent public URLs for local modifications. Use a version/commit-specific official link only when those remote bytes were actually read.

Manual: title, chip, manual revision, **physical page N**, table/section and an authorized original-file link. Opening must recheck credentials. Do not put personal bearer tokens into URLs or answers.

Only cite read material as evidence. Inaccessible hits may be listed as unverified leads. Mark missing units, unknown versions, uncertainty and cache dates explicitly. Related-material cards are generated from actual results and may include sources not cited in the answer.
