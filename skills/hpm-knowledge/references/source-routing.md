# Source routing

Peripheral setup and troubleshooting: official KB article search, then original body. Unknown-version articles can provide context but require applicability checks.

APIs, macros and initialization: current project's explicitly selected SDK root, then personal roots; prefer samples plus README before tracing drivers and declarations. SDK roots are readable only on the Harness Host. Multiple versions require project selection or an explicit version; do not choose highest automatically. Inaccessible SDKs may use the corresponding version's official online examples, documentation and source.

Pins, registers, values and timing: exact chip/manual revision, physical page and complete table. A related chip is not a substitute. Manual service searches remain private; missing manuals must not trigger public submission of an internal question.

Tools may be combined with native web_search, web_fetch and file readers, with no mandatory global call order. Official domain restrictions apply to this adapter's query only; other public sources remain available through native tools with suitability labeled.
